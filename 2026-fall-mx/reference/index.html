HTML Basics

HTML consists of a series of elements, which you use to enclose, wrap, or mark up different parts of content to make it appear or act in a certain way. HTML elements are written with "tags", a < symbol, the name of the HTML element, and a > symbol.

When one HTML element contains content (like other elements or text), the HTML element’s start tag is before the content and it’s end tag is after the content. The ending tag has a / before the HTML element name. For example, here is a paragraph (p) element:

HTML Boilerplate

These 4 items are required in any well-formed HTML document.

<!DOCTYPE html>
<html lang="en">
  <head>
    <!-- Metadata elements go here. -->
  </head>
  <body>
    <!-- Document content goes here. -->
  </body>
</html>
<!doctype html> — Document type declaration

This special tag declares that we are using the modern HTML version and not the old, out-dated “quirks” version of HTML.

This element contains information related to the document that is not the document’s content, for example, stylesheet links, meta tags, page title, etc.

This is not to be confused with the <header> element.

Document metadata

<title> </title> — Document title element

The title of the document is displayed in the web browser's tab.

MDN Reference for title

<style> </style> — Inline CSS styles element

This element contains CSS that is applied to the current document.

MDN Reference for style

<link rel="stylesheet" href="some-file.css" /> — CSS stylesheet link element

This link loads a CSS file to style the web page.

MDN Reference for link

<meta name="color-scheme" content="light dark" /> — Color scheme meta tag

Tells the browser which color scheme to use.

content="dark" means to use dark mode.
content="light" means to use light mode.
content="light dark" means to use the color scheme currently in-use by the Operating System (Windows, MacOS, Linux, etc.)

Content sections

<main> </main> — Main content element

The main content area contains the central topic of a document.

MDN Reference for main

<header> </header> — Header element

The header contains elements that describe the website such as a logo, navigational aids, a search form, an author name, and other elements.

Not to be confused with the <head> element.

MDN Reference for header

<footer> </footer> — Footer element

A footer typically contains information about the author of the section, copyright data or links to related documents.

<h1> </h1> … <h6> </h6> — Heading elements

Headings introduce the text below it. <h1> is the highest (or most important) section level and <h6> is the lowest.

<div> </div> — Content division element

This element is a generic container for content. Only use this element if you cannot find a better element for the content and you need to style the content using a class="" attribute.

<figure> </figure> — Figure element

A figure is an image, chart or table that is self-contained content, with an optional caption. The figure, its caption, and its contents are referenced as a single unit within the rest of the document.

This element is a caption or legend describing the rest of the contents of its parent <figure> element.

Media

<img src="some-file.jpg" > — Image element

This element loads an image into the document.

Supported image types include:

  • .gif
  • .jpg or .jpeg
  • .png
  • .webp
  • .svg
  • .avif
  • .jxl

If the image is part of the main content of the page, it should be wrapped inside a <figure> element.

Forms

<button> </button> — Button element

This element is an interactive element activated by a user using a mouse, keyboard, finger, etc. Once activated, it then performs an action, such as submitting a form or one specified with JavaScript.

MDN Reference for button

<input> — Form input

This element is used to create an interactive field of a form in order to accept data from the user. A wide variety of types of input data and control widgets are available; the type of input is controlled by the type="" attribute.

The different types of form input elements
HTML code Form element appearance Notes
<input type="text"> The most basic form input
<input type="email"> The web browser may verify that it is a valid email address
<input type="number"> Only integers and decimal numbers may be input
<input type="password"> The input will be hidden as the user types
<input type="search"> When text is entered, the browser will show a "clear" button so the user can easily start a new search
<input type="tel"> The web browser may verify that it is a valid phone number
<input type="checkbox" name=""> Indicates if the option is chosen or not. Multiple checkboxes can use the same name attribute and more than one of them can be checked at the same time.
<input type="radio" name=""> Indicates if the option is chosen or not. Multiple radio buttons can use the same name attribute but only one of them can be chosen at any time.
<input type="color"> Allows the user to easily pick a color
<input type="date"> Allows the user to easily pick a date
<input type="file"> Allows the user to pick a file from their computer
<input type="range"> Allows the user to pick a number from a range of numbers

MDN Reference for input

<label> </label> — Form element label

The label is a caption for a form field (<input>). Clicking on the label will cause the form field it captions to be activated.

The label can caption a form field in one of two ways:

  1. Wrapping:

    Wrap the label around the form input element.

    <label>
  First name:
  <input name="firstName" type="text">
</label>
  2. Using the for attribute:

    Add a for attribute that uses the id of the form input element. 

    <label for="first">
  First name:
</label>
<input id="first" name="firstName" type="text">

MDN Reference for label

<fieldset> </fieldset> — Set of form fields

This element groups several form elements together. It should contain a <legend> that captions the group. 

<fieldset>
  <legend>Name</legend>

    <input name="last" type="text">
