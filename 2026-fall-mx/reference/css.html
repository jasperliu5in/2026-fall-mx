CSS Basics

CSS rule (or CSS ruleset) selector { property: value; }

A set of styles that apply to one selection of HTML.

Example:

h1 {
  color: red;
  font-size: 2.5em;
}

MDN Reference

Nested statement selector1 { selector2 {} } 
/* Style all h1 elements */
h1 {
  color: red;
  font-size: 2.5rem;

  /* Style small elements that are inside an h1 element */
  small {
    font-size: 1rem;
  }
}

CSS Selectors

Type selector tag {}

The CSS type selector matches HTML elements by name.

Examples:

/* Styles all p elements. */
p { margin-block: 20px; }

/* Styles all h1 elements. */
h1 { margin-block: 20px 10px; }

MDN Reference for type selectors

Class selector .class {}

The CSS class selector matches elements based on the contents of their class attribute.

Examples:

/* All elements with class="spacious" */
.spacious {
  margin: 2em;
}

/* All <li> elements with class="spacious" */
li.spacious {
  margin: 2em;
}

/* All <li> elements with a class list that
   includes both "spacious" and "elegant".
   For example, <li class="elegant retro spacious"> */
li.spacious.elegant {
  margin: 2em;
}

MDN Reference for class selectors

ID selector #id {}
/* Style the element with an id attribute of "movie".
   For example, <article id="movie"> */
#movie {
  color: purple;
}

MDN Reference for class selectors

Universal selector * {}
/* Style all html elements. */
* {
  color: purple;
}
